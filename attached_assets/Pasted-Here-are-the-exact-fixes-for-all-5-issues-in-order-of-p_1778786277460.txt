## Fix 2 — Persist jobs with Replit DB

Replit has a built-in key-value store. The catch: it can't store raw bytes directly, so you base64-encode the clean file.

**Replace your in-memory `JOBS = {}` in `main.py` with this:**

```python
import os
import json
import base64
from replit import db  # built-in on Replit, no install needed

def save_job(job_id: str, job_data: dict):
    """Persist job to Replit DB. Encode bytes fields as base64."""
    serializable = job_data.copy()
    if "clean_bytes" in serializable:
        serializable["clean_bytes"] = base64.b64encode(
            serializable["clean_bytes"]
        ).decode("utf-8")
    db[f"job:{job_id}"] = json.dumps(serializable)

def load_job(job_id: str) -> dict | None:
    """Load job from Replit DB. Decode base64 bytes fields."""
    raw = db.get(f"job:{job_id}")
    if not raw:
        return None
    job_data = json.loads(raw)
    if "clean_bytes" in job_data:
        job_data["clean_bytes"] = base64.b64decode(job_data["clean_bytes"])
    return job_data
```

**Update your `/api/scrub` route** — replace `JOBS[job_id] = {...}` with `save_job(job_id, {...})`.

**Update your `/api/download/<job_id>` route:**

```python
@app.route("/api/download/<job_id>")
def download(job_id):
    job = load_job(job_id)  # was: JOBS.get(job_id)
    if not job:
        return jsonify({"error": "Job not found or expired"}), 404
    return send_file(
        BytesIO(job["clean_bytes"]),
        download_name=f"clean_{job['filename']}",
        as_attachment=True
    )
```


This means even if the DB lookup fails for any reason, the judge still has the Walrus URL as a recovery path.
